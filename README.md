# windows-dfir-lab48-suspicious-dll-execution-investigation
Windows DFIR investigation of a simulated suspicious DLL artifact using Sysmon, Windows Security Event ID 4688, Event Viewer, PowerShell, file metadata, SHA-256 hashing, Authenticode analysis, process creation, network telemetry, and evidence correlation, including investigation of unavailable Sysmon Event ID 7 Image Load telemetry.
